# Spring Boot 3.0 的关键底层迁移

Spring Boot 3.0 最关键的底层迁移是从 Java EE 命名空间迁移到 **Jakarta EE 9+**（包名由 javax 变为 jakarta），应用代码与依赖需同步升级。其基座同时升级到 Spring Framework 6.0，并要求 Java 17 及以上。
